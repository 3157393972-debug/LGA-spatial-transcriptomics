# Data access and reproducibility limitations

This repository should not include raw DLPFC or mouse .h5ad matrices unless redistribution rights have been checked. Data accession/source information and preprocessing details should accompany a future release.

The original multi-section experiments, independent PCA/GraphSAGE verification, and mouse pseudo-label evaluation are distinct protocols. Mouse pseudo-label agreement must not be described as an independent anatomical ground-truth benchmark.

Historical code may contain environment-specific `/root/autodl-tmp/` paths and should be considered an archival provenance record, not a portable end-to-end pipeline.
