# Author release checklist

- [ ] Confirm which journal submission version and manuscript figures this commit supports.
- [ ] Verify code rights, data redistribution terms and any dependencies used.
- [ ] Replace absolute AutoDL paths with configurable paths for every **advertised runnable** script.
- [ ] Lock and test environment; verify reproduction from a fresh checkout.
- [ ] Keep raw h5ad, private embeddings, logs and credentials out of git unless separately authorized.
- [ ] Verify independent GraphSAGE and revised Figure 6, plus original Figure 2–4 results and supplements against code version.
- [ ] Confirm the mouse case is described as pseudo-label agreement, not independent biology.
- [ ] Confirm manuscript/rebuttal and AI disclosures and source acknowledgements with authors.
- [ ] Select and add a verified license if authorized.
- [ ] Only after signoff: change Private -> Public, use a release tag and optionally connect an archive for DOI.
